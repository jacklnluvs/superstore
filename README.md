# Superstore Sales Data Analysis

## About the Project

This project is a simple data analysis of the Superstore dataset using Python in Google Colab.

The main purpose of this project is to understand sales, profit, discount, and category performance using basic data analysis and visualization.

## Tools Used

- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

## Dataset

The Superstore dataset contains information about:

- Sales
- Profit
- Discount
- Category
- Sub-Category
- Customers
- Products
- Orders

## Analysis Performed

In this project, I performed the following analysis:

1. Loaded the Superstore dataset.
2. Displayed the first 5 rows of the dataset.
3. Created a bar chart to show total Sales for each Category.
4. Created a box plot to understand Profit distribution.
5. Created a scatter plot between Discount and Profit.
6. Created a correlation matrix for numerical columns.
7. Created a heatmap to visualize the correlation matrix.
8. Found the Category with the highest total Profit.
9. Identified simple business insights from the analysis.

## Visualizations

### Sales by Category

A bar chart was used to compare the total sales of different categories.

### Profit Distribution

A box plot was used to understand the distribution of profit and identify possible outliers.

### Discount vs Profit

A scatter plot was used to observe the relationship between discount and profit.

### Correlation Heatmap

A heatmap was used to understand the relationship between numerical columns.

## Business Insights

Some simple insights from the analysis are:

- Sales are different across the categories.
- Discounts can have an effect on profit.
- Some categories generate more profit than others.
- The category with the highest profit can be considered for future business growth.

## Conclusion

This project helped me understand the basics of data analysis using Python. I learned how to group data, calculate totals, create visualizations, and find simple business insights from a dataset.
